# Game Sales Analytics Dashboard

A web-based analytics dashboard for exploring and visualizing global video game sales data across different regions, genres, platforms, and publishers.

Built with a lightweight frontend using pure HTML, CSS, and JavaScript, and powered by a Flask + Pandas backend for data processing and analytics.

---

## Features

- Interactive sales dashboard
- Regional sales comparison
- Genre and publisher analytics
- Dynamic filtering and sorting
- REST API integration with Flask
- Data cleaning and aggregation using Pandas
- Interactive charts and visualizations with Chart.js
- Responsive frontend interface

## Data Processing Workflow

1. Load raw CSV dataset using Pandas
2. Clean missing and inconsistent data
3. Aggregate regional and global sales metrics
4. Serve processed analytics through Flask REST APIs
5. Render interactive visualizations using Chart.js
